# Open issues

`consolidated-open-questions.md` là mục lục các open question đang mở theo product/object (số lượng theo loại, link tới `open-questions.md` của object). File được sinh tự động, không sửa tay.

Nội dung từng câu hỏi nằm ở `products/<product>/<object>/open-questions.md`; mỗi câu có `oq_id`. Thư mục này không chứa ghi chú viết tay.
